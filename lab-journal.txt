- Spend history and current spend are different things.

------------------------------------------------------------
KEY LEARNINGS
------------------------------------------------------------
Concepts
- Cost Analysis shows where money went (resource group, service,
  resource type, tag). A budget shows when a limit is crossed.
- A budget is a notification, not a control. Automatic action needs an
  action group and extra automation.
- Actual alerts fire after money is spent. Forecast alerts fire when
  Azure predicts a breach.
- A tag on a resource group does not flow to its resources' cost records
  unless tag inheritance is enabled.
- Untagged spend is what a required-tag policy exists to prevent.
- Advisor only recommends and never acts. Its data can lag behind
  deletions. VM right-sizing advice needs about 7 days of usage data.
- Advisor categories: Cost, Security, Reliability, Operational
  Excellence, Performance.
- Cost Management exports send cost data as files to a storage account.

Gotchas
- Clicking a chart segment in Cost Analysis adds a filter that must be
  cleared with the X on the filter pill.
- Budget start dates are fixed to the 1st of the month in the Portal.

Errors and checks
- A negative budget amount was rejected by form validation. Budgets are
  structured objects with rules.
- Advisor's reliability recommendations contradicted an empty resource
  list. Check the real subscription state before trusting a report.

Commands used (in words)
- List all resources in the subscription.
- List resource group names with a query.
- Show the current subscription name to confirm the CLI target.
